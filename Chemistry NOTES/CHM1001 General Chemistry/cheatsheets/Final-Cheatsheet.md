    **-First Order Reactions**: The rates depend only on one reactant to the first power.

    The rate law becomes: <span class="mark">Rate = k\[A\]</span>

    rate = k\[A\]

    k\[A\] = −Δ \[A\] / Δt

    Rearrange: <span class="mark">ln\[A\] = −kt + ln \[A\]<sub>o</sub></span>

    →从图中找k，斜率为k

    (?A为反应物?)

    Half-life半衰期: ln 2 = k t½ or t½ = 0.693/k

    \-**Second Order Reactions**

    Def.: The rates depend only on a reactant to the second power.

    The rate law becomes: <span class="mark">Rate = k\[A\]<sup>2</sup></span>

    k \[A\]<sub>2</sub> = −Δ\[A\] / Δ t

    Using calculus: <span class="mark">1/\[A\] = 1/\[A\]<sub>o</sub> + k t</span>

    E.g. NO2→NO+(1/2)O<sub>2</sub>

    Its second order rate = k\[NO2\]<sup>2</sup>

    Half-life<span class="mark">半衰期: t½ = 1 / (k \[A\]<sub>o</sub>)</span>

    So half-life is a concentration dependent quantity for second order reactions!

    -Zero Order Reactions

    rate is independent of the concentration of the reactant ; <span class="mark">Rate = k</span>

    <span class="mark">These reactions are linear in concentration</span>.
