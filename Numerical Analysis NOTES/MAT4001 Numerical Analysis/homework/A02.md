## Q1

$\forall c \in [a, b]$: $f(x) = f(c) + f'(c)(x - c) + \frac{f''(\xi)}{2}(x - c)^2$, $\exists\xi \in [c, x]$ if $c \le x$, or $\xi \in [x, c]$ if $c \ge x$.

$f(a) = f(b) = 0$ ⇒ $\exists c_0 \in [a, b]$ s.t. $f'(c_0) = 0$:

$$f(x) = f(c_0) + \frac{f''(\xi)}{2}(x - c_0)^2 \Rightarrow f(x) \le f(c_0) + \frac12(x - c_0)^2\max_{a\le x\le b}|f''(x)|$$
$$f(x) \le f(c_0) + \frac18(b - a)^2\max_{a\le x\le b}|f''(x)|$$

$f'(c_0) = 0$ ⇒ if $\max_{a\le x\le b}|f(x)| = |f(x_0)|$, then $x_0$ is fit for $c_0$:

$$\max_{a\le x\le b}|f(x)| \le f(x) - f(c_0) \le \frac18(b - a)^2\max_{a\le x\le b}|f''(x)|$$
