## 修正

- 直接光被遮挡时只令直接光贡献为零，继续计算间接光。
- 距离平方使用真正的向量长度平方，避免把标量转换为三维向量后得到三倍的距离平方。
- 阴影光线从表面略微偏移，只检查到采样灯面之前的线段；求交忽略零距离、负距离和线段范围外的结果。
- 光照余弦限制为非负值，避免灯面背面产生负贡献。
- 间接反射使用当前表面的材质，采样方向与 PDF 一致；使用余弦加权半球采样降低方差。
- 灯面 BVH 按面积均匀选择三角形，修正原来的平方根偏置；灯光 PDF 包含选择发光对象的概率。
- 样本累积除以实际采样数，修正原来除以 `spp / 2` 的两倍曝光。
- 像素内随机采样改善锯齿；线程局部随机数与固定像素种子支持可重复的并行计算。
- 前三层继续追踪，此后用原来的 0.8 存活概率做俄罗斯轮盘终止，并按概率补偿权重。
- 输出 PNG 和 PPM；渲染时检查每个像素的线性颜色是否有限且非负。

## 验证

`render_checks` 检查有效光线区间、均匀灯面采样、采样方向与 PDF 的一致性，
以及天花板／矮箱子背光面在没有直接光时仍然能获得间接光。
正式渲染前已通过构建、测试和 192 × 192 预览检查。

## 重现

在 `GAMES101/PA7/PA7` 目录运行：

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
ctest --test-dir build -C Release --output-on-failure
# Linux / WSL：
OMP_NUM_THREADS=16 ./build/RayTracing 1024 1024 100
# Windows 多配置生成器：
./build/Release/RayTracing.exe 1024 1024 100
```

三个可选参数依次是图像边长、每像素采样数和最大路径深度；默认即本次配置。
运行目录应包含 `cornellbox` 模型目录；输出为 `binary.png` 和 `binary.ppm`。
PNG 编码复用本地 Project2 中已有的 `stb_image_write.h`（保留其许可证）。

被修改的旧源码和旧渲染文件保存在 `PA7_source_backup_20260926`。
