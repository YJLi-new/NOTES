- 为静止／运动球生成有效的包围盒；BVH 单对象叶子只求交一次，避免重复抽样体积事件。
- 修正帧缓冲行跨度与多渲染一行／一列的问题。
- 次级光线继承时间，保留一致的运动模糊。

- 直接写出 PNG 和 PPM，并检查非有限颜色值及输出失败。

## 重现

在 `RayTracingInOneWeekend/Project2/Project1` 目录：

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
ctest --test-dir build -C Release --output-on-failure
# Linux / WSL，当前目录应有 earthmap.jpg：
OMP_NUM_THREADS=16 ./build/Project2Render 1024 2048 32
# Windows 多配置生成器：
./build/Release/Project2Render.exe 1024 2048 32
```

三个可选命令行参数分别为正方形图像边长、每像素采样数和递归深度上限；
默认值即 1024、2048、32。输出到运行目录的 `binary.png` 和 `binary.ppm`。
`RTW_IMAGES` 环境变量可指定地球纹理所在目录。

`render_checks` 检查随机方向、球体包围盒／交点、有限介质散射概率、
BVH 求交，以及混合采样在恒定入射光下的能量一致性。
