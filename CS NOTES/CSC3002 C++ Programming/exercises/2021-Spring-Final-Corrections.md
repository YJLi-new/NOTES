	-在 C++ 和许多其他编程语言中，每个子表达式的类型都会在计算的每个步骤中进行评估并可能进行转换，而不是立即确定整个表达式的类型。 此过程称为类型提升或类型强制，它根据特定规则发生
	1. **整数运算：** 如果运算中的两个操作数都是整数，则该运算按整数运算执行。 例如，在整数除法中，结果被截断为整数。
	2. **混合类型运算：** 当运算涉及不同类型的操作数（例如整数和浮点数）时，“较低”类型将提升为“较高”类型。 例如，在涉及整数和双精度数的运算中，整数被提升为双精度数，并且该运算作为浮点运算来执行。
	3. **结果类型：** 表达式中的每个单独的操作都根据这些规则计算其结果，并且每个操作的结果的类型会影响后续操作。
	-在表达式“9 * (8 - 7) / 6 + 5 * 4 % 3 * (2 + 1.0)”中，初始运算是整数运算（“9 * (8 - 7) / 6”和“5 * 4” % 3`），但表达式的后半部分涉及浮点数（`1.0`），这将最终运算提升为浮点运算。

	在 C++ 中，类的数据成员是在类内声明的变量。 这些属性保存了类的对象可能包含的数据。 数据成员可以是 C++ 支持的任何类型，包括“int”和“double”等基本类型，以及其他类、结构、联合和数组。
	访问说明符“private”和“protected”决定了 C++ 中类成员的可访问性：
	- **私有：** 当数据成员声明为“私有”时，它们只能由属于同一类的成员的函数访问。 这是最严格的封装级别，用于确保类数据不能从类外部直接操作，保持数据的完整性。
	- **受保护：** “受保护”数据成员与“私有”类似，因为它们不能在类外部访问，除了友元类之外。 但是，可以在派生类（子类）中访问它们。 这提供了一定程度的封装，同时仍然允许子类可以访问和操作继承的数据成员的继承层次结构。
	面向对象编程中的封装原则表明类应该隐藏其内部数据并仅公开其接口的必要部分。 通过将数据成员声明为“私有”，类可以控制其数据的访问和修改方式，这有助于保护数据的完整性，并确保仅通过类的方法以可预测的方式更改数据。 --> c.private
