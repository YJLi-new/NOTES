## 4 Tensor Product

(Motivation: illustrate $k$-linear maps.)

**Def.** Let $V_1,\dots,V_k, W$ be vector spaces. A **$k$-linear map** is a function $\phi: V_1\times\cdots\times V_k \to W$ s.t.

$$\phi(v_1,\dots,v_i + v_i',\dots,v_k) = \phi(v_1,\dots,v_i,\dots,v_k) + \phi(v_1,\dots,v_i',\dots,v_k)$$
$$\phi(v_1,\dots,\alpha v_i,\dots,v_k) = \alpha\phi(v_1,\dots,v_k)$$

**E.g.**

1. All bilinear forms $\langle\,,\rangle: V\times V \to \mathbb{F}$ are 2-linear.
2. $\times: \mathbb{R}^3\times\mathbb{R}^3 \to \mathbb{R}^3$, $(u, v) \mapsto u\times v$ (cross product) is 2-linear.
3. $V = M_{n\times n}(\mathbb{F})$, $\phi: \underbrace{V\times\cdots\times V}_{k\text{ copies}} \to V$, $\phi(M_1,\dots,M_k) = M_1\cdots M_k$ is $k$-linear.
4. $\det: \underbrace{\mathbb{F}^n\times\cdots\times\mathbb{F}^n}_{n\text{ copies}} \to \mathbb{F}$, $(c_1,\dots,c_n) \mapsto \det(c_1 \mid \cdots \mid c_n)$ is $n$-linear.

There is a vector space structure on $V_1\times\cdots\times V_k$:

1. $\mathbf{0}_V = (\mathbf{0}_{V_1},\dots,\mathbf{0}_{V_k})$
2. $(v_1,\dots,v_k) + (v_1',\dots,v_k') = (v_1 + v_1',\dots,v_k + v_k')$
3. $\alpha(v_1,\dots,v_k) = (\alpha v_1,\dots,\alpha v_k)$ ((exterior) direct sum)

But a $k$-linear map $\phi: V_1\times\cdots\times V_k \to W$ ($\phi \ne \mathbf{0}$) **cannot** be a linear transformation (若是, 则能用 matrix rep. 来 understand $\phi$).
E.g. $\phi(2(v_1, v_2)) \overset{(3)}{=} \phi(2v_1, 2v_2) = 2\phi(v_1, 2v_2) = 2\cdot 2\phi(v_1, v_2) \ne 2\phi(v_1, v_2)$.
(Also $\det(\alpha M) = \alpha^n\det(M)$: $\det$ is $n$-linear, not linear.)

### Want to do

1. Construct the tensor product space $V_1\otimes\cdots\otimes V_k$.
2. Define an injection $i: V_1\times\cdots\times V_k \to V_1\otimes\cdots\otimes V_k$ (s.t. $\forall(v_1,\dots,v_k) \in V_1\times\cdots\times V_k$ is uniquely "represented" by $v_1\otimes\cdots\otimes v_k$).
3. All $k$-linear maps $\phi: V_1\times\cdots\times V_k \to W$ can be expressed as $\phi = \Phi\circ i$:

$$V_1\times\cdots\times V_k \xrightarrow{\ i\ } V_1\otimes\cdots\otimes V_k \xrightarrow{\ \Phi\ } W$$

with $\phi$ $k$-linear (not a linear trans.) and $\Phi$ a linear trans., i.e. study $\Phi$ → understand $\phi$.

## Construction of $V_1\otimes\cdots\otimes V_k$ (not examinable)

For simplicity, only do $k = 2$ ($V\otimes W$).

Let $\mathcal{S} := \{\{v, w\} \mid v \in V, w \in W\}$ and $\mathcal{X} := \operatorname{Span}(\mathcal{S})$, i.e. elements in $\mathcal{X}$ are of the form $3\{v_1, w_1\} + \pi\{v_2, w_2\} + e^{15}\{v_3, w_3\}$ (formal combinations).

Warning: $v_1 \ne v_2$ and $w_1 \ne w_2$ ⇒ $\{v_1, w_1\}$ 与 $\{v_2, w_2\}$ 无关.
Therefore $\mathcal{S}$ is a basis of $\mathcal{X}$ ($= \{\{0,0\}, \{v, 0\}, \{\pi v, 0\}, \{ev, 0\}, \{e^\pi v, 0\}, \dots\}$), a "very" $\infty$-dim space.

Let $\mathcal{Y} \le \mathcal{X}$ be the subspace spanned by (in $\mathcal{X}$):

$$\mathcal{Y} = \operatorname{Span}\left\{\begin{aligned}&\{kv, w\} - k\{v, w\}\\ &\{v, lw\} - l\{v, w\}\\ &\{v + v', w\} - \{v, w\} - \{v', w\}\\ &\{v, w + w'\} - \{v, w\} - \{v, w'\}\end{aligned}\ \middle|\ k, l \in \mathbb{F},\ v, v' \in V,\ w, w' \in W\right\}$$

($\mathcal{Y}$ is also a "very" $\infty$-dim space.)

**Def. ($V\otimes W$).** $V\otimes W := \mathcal{X}/\mathcal{Y}$.

**Def. ($v\otimes w$).** $\forall v \in V$ and $w \in W$, $v\otimes w := \{v, w\} + \mathcal{Y} \in \mathcal{X}/\mathcal{Y} = V\otimes W$.

## Arithmetic on $V\otimes W$

**E.g.**

1. $(2v)\otimes w = \{2v, w\} + \mathcal{Y} = \{2v, w\} - \underbrace{(\{2v, w\} - 2\{v, w\})}_{\in\mathcal{Y}} + \mathcal{Y} = 2\{v, w\} + \mathcal{Y} = 2(\{v, w\} + \mathcal{Y}) = 2(v\otimes w)$.
   Similarly, $v\otimes(ew) = e(v\otimes w)$.
2. $(v + v')\otimes w = \{v + v', w\} + \mathcal{Y} = \{v + v', w\} - (\{v + v', w\} - \{v, w\} - \{v', w\}) + \mathcal{Y} = \{v, w\} + \{v', w\} + \mathcal{Y} = (\{v, w\} + \mathcal{Y}) + (\{v', w\} + \mathcal{Y}) = v\otimes w + v'\otimes w$.

**Conclusion 2.** $(v + v')\otimes w = (v\otimes w) + (v'\otimes w)$; $v\otimes(w + w') = (v\otimes w) + (v\otimes w')$.

3. In $\mathbb{R}^2\otimes\mathbb{R}^3$, let $e_1 = (1,0)^T$, $e_2 = (0,1)^T$, $f_1 = (1,0,0)^T$, $f_2 = (0,1,0)^T$, $f_3 = (0,0,1)^T$:
   $$\begin{pmatrix}1\\2\end{pmatrix}\otimes\begin{pmatrix}3\\4\\5\end{pmatrix} = (e_1 + 2e_2)\otimes(3f_1 + 4f_2 + 5f_3) = e_1\otimes(3f_1 + 4f_2 + 5f_3) + (2e_2)\otimes(3f_1 + \cdots)$$
   $$\overset{(2)+(1)}{=} e_1\otimes(3f_1) + e_1\otimes(4f_2) + e_1\otimes(5f_3) + 2[e_2\otimes(3f_1 + 4f_2 + 5f_3)] = 3(e_1\otimes f_1) + \cdots$$

**Warning 2.** Not all vectors in $V\otimes W$ are of the form $v\otimes w$. A general vector in $V\otimes W = \mathcal{X}/\mathcal{Y}$ is of the form $\sum_i v_i'\otimes w_i$ ($\forall i$, $v_i' = \alpha_iv_i$).

**Remarks.**

1. $\{v_1,\dots,v_m\}$ is a basis of $V$ and $\{w_1,\dots,w_n\}$ a basis of $W$ ⇒ (Warning 2) $\{v_i\otimes w_j \mid i \in \{1,\dots,m\}, j \in \{1,\dots,n\}\}$ spans $V\otimes W$ — 其实是 basis ⇒ $\dim(V\otimes W) = \dim(V)\cdot\dim(W)$.
