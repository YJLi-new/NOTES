## Diagonalizability via $m_T$

**Prop.** $T: V \to V$ is diagonalizable $\Rightarrow m_T(x) = (x - \mu_1)\cdots(x - \mu_k)$, $\mu_i$'s distinct. (后证 ⇐; 用来判断 $T$ 是否 diag.-able)

e.g. $m_T(x) = (x - 1)^2$ (not distinct) $\Rightarrow T$ is not diag.-able; $m_T(x) = (x - 1)$ (distinct) $\Rightarrow T$ is diag.-able.

*Proof.* Let $B$ be a basis of $V$ s.t. $(T)_{BB} = \operatorname{diag}(\mu_1,\dots,\mu_k)$ (eigenvalues listed with repetition).

1. $(T_{BB} - \mu_1I_{n\times n})\cdots(T_{BB} - \mu_kI_{n\times n}) = 0_{n\times n}$ (Ex.).
   Let $p(x) = (x - \mu_1)\cdots(x - \mu_k)$. Then $p(T)_{BB} = 0_{n\times n} \Rightarrow p(T) = \mathbf{0}_{V\to V} \Rightarrow m_T(x) \mid p(x)$.
2. If you omit any factor $(x - \mu_i)$ of $p(x)$ (省略/遗漏/排除), e.g. $q(x) = (x - \mu_1)\cdots(x - \mu_{i-1})(x - \mu_{i+1})\cdots(x - \mu_k)$, then $q(T)_{BB} \ne 0_{n\times n}$
   $\Rightarrow q(x) \ne m_T(x) \Rightarrow m_T(x) = p(x)$.

## Primary Decomposition Theorem (PDT) and Diagonalizability Theorem

(Idea: "decompose" $T$ into $T|_{V_1}: V_1 \to V_1, \dots, T|_{V_k}: V_k \to V_k$.)

$T: V \to V$ a linear operator, $\dim(V) < \infty$, $m_T(x) = [p_1(x)]^{e_1}\cdots[p_k(x)]^{e_k}$. Let $V_i = \ker(p_i(T)^{e_i})$. Then:

1. $\forall i$, $V_i$ is $T$-invariant (i.e. $T(V_i) \le V_i$);
2. $V = V_1 \oplus \cdots \oplus V_k$;
3. $T|_{V_i}$ has $m_{T|_{V_i}}(x) = p_i(x)^{e_i}$.

*Proof.* Consider $q_i(x) := \dfrac{m_T(x)}{p_i(x)^{e_i}} = p_1(x)^{e_1}\cdots p_{i-1}(x)^{e_{i-1}}p_{i+1}(x)^{e_{i+1}}\cdots p_k(x)^{e_k}$.

1. $\gcd(q_1(x),\dots,q_k(x)) = 1 \overset{\text{Bézout}}{\Rightarrow} a_1(x)q_1(x) + \cdots + a_k(x)q_k(x) = 1$ (for polys $a_i(x)$).
2. $\gcd(q_i(x), p_i(x)^{e_i}) = 1 \overset{\text{Bézout}}{\Rightarrow} b_i(x)q_i(x) + c_i(x)p_i(x)^{e_i} = 1$.
3. $q_i(x)p_i(x)^{e_i} = m_T(x)$.
4. If $i \ne j$, $m_T(x) \mid q_i(x)q_j(x)$.

**Claim 1.** $\ker(p_i(T)^{e_i})$ $(= V_i)$ is $T$-invariant.
*Proof.* Let $v \in \ker(p_i(T)^{e_i})$; then $p_i(T)^{e_i}(v) = \mathbf{0}$. Consider
$$p_i(T)^{e_i}(T(v)) \overset{(*)}{=} T[p_i(T)^{e_i}(v)] = T(\mathbf{0}) = \mathbf{0} \Rightarrow T(v) \in \ker(p_i(T)^{e_i})$$
(Recall: in general, $\forall A, B: V \to V$, $AB \ne BA$. However $h(T) = f(T)g(T) = g(T)f(T)$ where $h(x) = f(x)g(x)$. For $(*)$, take $f(x) = p_i(x)^{e_i}$, $g(x) = x$.)

**Claim 2.** $V = V_1 + \cdots + V_k$, where $V_i := \ker(p_i(T)^{e_i})$.
*Proof.* By ①, $a_1(T)q_1(T) + \cdots + a_k(T)q_k(T) = I$
$\Rightarrow a_1(T)q_1(T)(v) + \cdots + a_k(T)q_k(T)(v) = I(v) = v$, $\forall v \in V$.
Let $v_i = a_i(T)q_i(T)(v)$ $\Rightarrow v_1 + \cdots + v_k = v$.
Note: $v_i$ in $(*)$ is in $V_i$: $p_i(T)^{e_i}(a_i(T)q_i(T)(v)) \overset{\text{recall}}{=} a_i(T)p_i(T)^{e_i}q_i(T)(v) \overset{③}{=} a_i(T)m_T(T)(v) = a_i(T)(\mathbf{0}) = \mathbf{0}$.

**Claim 3.** $V = V_1 \oplus V_2 \oplus \cdots \oplus V_k$.
*Proof.* Suppose $v_1' + \cdots + v_k' = \mathbf{0}$ where $v_i' \in V_i = \ker(p_i(T)^{e_i})$. (WTS: $v_1' = \cdots = v_k' = \mathbf{0}$.)
By ②, $b_i(T)q_i(T) + c_i(T)p_i(T)^{e_i} = I$
$\Rightarrow b_i(T)q_i(T)(v_i') + c_i(T)p_i(T)^{e_i}(v_i') = I(v_i') = v_i'$
$\Rightarrow b_i(T)q_i(T)(v_i') = v_i'$ (since $p_i(T)^{e_i}v_i' = \mathbf{0}$).
Now apply $b_i(T)q_i(T)$ to $v_1' + \cdots + v_k' = \mathbf{0}$:
LHS: $b_i(T)q_i(T)v_1' + \cdots + b_i(T)q_i(T)v_i' + \cdots + b_i(T)q_i(T)v_k'$. For $j \ne i$, $q_i$ contains the factor $p_j(T)^{e_j}$, e.g. $b_i(T)q_i(T)v_1' = b_i(T)p_2(T)^{e_2}\cdots p_k(T)^{e_k}\,p_1(T)^{e_1}(v_1') = \mathbf{0}$; so LHS $= v_i'$.
RHS: $b_i(T)q_i(T)(\mathbf{0}) = \mathbf{0}$. Hence $v_i' = \mathbf{0}$.

**Claim 4.** $T|_{V_i}: V_i \to V_i$ has $m_{T|_{V_i}}(x) = p_i(x)^{e_i}$.
*Proof.* Take $\forall v_i \in V_i = \ker(p_i(T)^{e_i})$. Then $p_i(T)^{e_i}(v_i) = \mathbf{0} \Rightarrow p_i(T|_{V_i})^{e_i}(v_i) = \mathbf{0}$
$\Rightarrow p_i(T|_{V_i})^{e_i}$ is the zero operator $\Rightarrow m_{T|_{V_i}}(x) \mid p_i(x)^{e_i}$.
Suppose on contrary $m_{T|_{V_i}}(x) = p_i(x)^{g_i}$ with $g_i < e_i$ $\Rightarrow p_i(T)^{g_i}(v) = \mathbf{0}$, $\forall v_i \in V_i$.
Consider $d(x) := p_1(x)^{e_1}\cdots p_i(x)^{g_i}\cdots p_k(x)^{e_k}$ $\Rightarrow \deg(d(x)) < \deg(m_T(x))$, and $\forall v \in V$, $v = v_1 + \cdots + v_k$ with $v_i \in V_i$:
$$d(T)(v) = \sum_{j=1}^k p_1(T)^{e_1}\cdots[p_j(T)^{e_j}v_j]\cdots p_k(T)^{e_k} = \mathbf{0} + \cdots + \mathbf{0} = \mathbf{0}$$
$\Rightarrow d(T) = \mathbf{0}_{V\to V} \Rightarrow \deg(d(x)) \ge \deg(m_T(x))$, which contradicts. Hence $g_i = e_i$.

**Corollary.** $m_T(x) = (x - \mu_1)\cdots(x - \mu_k)$, $\mu_i$'s distinct $\Rightarrow T: V \to V$ is diagonalizable.
*Proof.* By PDT, $V = V_1 \oplus \cdots \oplus V_k$ where $V_i := \ker(T - \mu_iI)$ (take $p_i(x)^{e_i} = (x - \mu_i)$) $\Rightarrow V_i$ is the $\mu_i$-eigenspace of $T$.
Take a basis $B_i$ of $V_i$ ($B_i$: basis of $\mu_i$-eigenvectors). Then $V = V_1 \oplus \cdots \oplus V_k \Rightarrow B := B_1 \cup \cdots \cup B_k$ is a basis of eigenvectors of $T$ $\Rightarrow T$ is diagonalizable.
