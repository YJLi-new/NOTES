Assume that $V_1 = \cdots = V_m = V$.

## Alternating map

**Def.** An $m$-linear map $f: \underbrace{V\times\cdots\times V}_{m\text{ copies}} \to U$ is **alternating** $\iff \forall w \in V$ and $i, j \in \{1,\dots,m\}$ ($i \ne j$):

$$f(v_1,\dots,\underset{i\text{th}}{w},\dots,\underset{j\text{th}}{w},\dots,v_m) = \mathbf{0}$$

**E.g.**

1. $\times: \mathbb{R}^3\times\mathbb{R}^3 \to \mathbb{R}^3$, $\times(w, w) := w\times w = \mathbf{0}$.
2. $\det: \underbrace{\mathbb{F}^n\times\cdots\times\mathbb{F}^n}_{n\text{ copies}} \to \mathbb{F}$: (MAT2040) $\det(\cdots \mid w \mid \cdots \mid w \mid \cdots) = 0$.

## Exterior tensor product

**Def.** The $m$-th exterior tensor product $\Lambda^mV$ of $V$ is

$$\Lambda^mV = \underbrace{(V\otimes\cdots\otimes V)}_{m\text{ copies}}/Z,\qquad Z = \operatorname{Span}\{\cdots\otimes w\otimes\cdots\otimes w\otimes\cdots \mid w \in V\}$$

$$v_1\wedge\cdots\wedge v_m := (v_1\otimes\cdots\otimes v_m) + Z \in (V\otimes\cdots\otimes V)/Z = \Lambda^mV$$

**E.g.** ($m = 4$) In $\Lambda^4V$:

1. **(Rule 1)** $w\wedge v\wedge u\wedge w = \underbrace{w\otimes v\otimes u\otimes w}_{\in Z} + Z = \mathbf{0} + Z = \mathbf{0}_{\Lambda^4V}$.
2. $(w + u)\wedge v\wedge(w + u)\wedge v' = \mathbf{0}_{\Lambda^4V}$. Expand:
   $(w + u)\otimes v\otimes(w + u)\otimes v' + Z = \mathbf{0}$
   ⇒ $(\underbrace{w\otimes v\otimes w\otimes v'}_{\in Z} + w\otimes v\otimes u\otimes v' + u\otimes v\otimes w\otimes v' + \underbrace{u\otimes v\otimes u\otimes v'}_{\in Z}) + Z = \mathbf{0}$
   ⇒ $w\wedge v\wedge u\wedge v' + u\wedge v\wedge w\wedge v' = \mathbf{0}$
   ⇒ **(Rule 2)** $w\wedge v\wedge u\wedge v' = -(u\wedge v\wedge w\wedge v')$.
3. (Whiteboard) $V = \mathbb{R}^3 = \operatorname{Span}\{e_1, e_2, e_3\}$. In $\Lambda^2\mathbb{R}^3$:
   $$\begin{pmatrix}1\\2\\3\end{pmatrix}\wedge\begin{pmatrix}4\\5\\6\end{pmatrix} = (e_1 + 2e_2 + 3e_3)\wedge(4e_1 + 5e_2 + 6e_3)$$
   $$= 4e_1\wedge e_1 + 8e_2\wedge e_1 + 12e_3\wedge e_1 + 5e_1\wedge e_2 + 10e_2\wedge e_2 + 15e_3\wedge e_2 + 6e_1\wedge e_3 + 12e_2\wedge e_3 + 18e_3\wedge e_3$$
   $$= (5 - 8)e_1\wedge e_2 + (6 - 12)e_1\wedge e_3 + (12 - 15)e_2\wedge e_3$$

**Prop.** Let $\dim(V) = n$ and $\{v_1,\dots,v_n\}$ be a basis of $V$. Then $\forall m \le n$, a basis of $\Lambda^mV$ is $\{v_{i_1}\wedge\cdots\wedge v_{i_m} \mid 1 \le i_1 < \cdots < i_m \le n\}$, and

$$\dim(\Lambda^mV) = \binom{n}{m} = \frac{n!}{m!(n - m)!}$$

- **E.g. 1.** $\dim(\Lambda^2\mathbb{R}^3) = \binom32 = 3$; a basis of $\Lambda^2\mathbb{R}^3$: $\{e_1\wedge e_2, e_1\wedge e_3, e_2\wedge e_3\}$.
- **E.g. 2 (whiteboard).** Example bases for
  - $\Lambda^1\mathbb{R}^4$: $\{e_1, e_2, e_3, e_4\}$
  - $\Lambda^2\mathbb{R}^4$: $\{e_1\wedge e_2, e_1\wedge e_3, e_1\wedge e_4, e_2\wedge e_3, e_2\wedge e_4, e_3\wedge e_4\}$
  - $\Lambda^3\mathbb{R}^4$: $\{e_1\wedge e_2\wedge e_3, e_1\wedge e_2\wedge e_4, e_1\wedge e_3\wedge e_4, e_2\wedge e_3\wedge e_4\}$
  - $\Lambda^4\mathbb{R}^4$: $\{e_1\wedge e_2\wedge e_3\wedge e_4\}$ — 1-dimensional.

**总结 (whiteboard).**

| | $V_1\otimes\cdots\otimes V_m$ | $\Lambda^mV$ |
|---|---|---|
| General element | $v_1^{(1)}\otimes\cdots\otimes v_m^{(1)} + \cdots + v_1^{(k)}\otimes\cdots\otimes v_m^{(k)}$ | $(v_1^{(1)}\wedge\cdots\wedge v_m^{(1)}) + \cdots + (v_1^{(k)}\wedge\cdots\wedge v_m^{(k)})$ |
| Dimension | $\dim(V_1)\cdots\dim(V_m)$ | $\binom nm = \frac{n!}{m!(n-m)!}$ |
| Universal property | $f: V_1\times\cdots\times V_m \to U$ $m$-linear ⇝ $\Phi: V_1\otimes\cdots\otimes V_m \to U$ linear trans. | $f: V\times\cdots\times V \to U$ alternating ⇝ $\Phi: \Lambda^mV \to U$ linear trans. |
| Linear trans. | $T_i: V_i \to V_i'$ ⇝ $T_1\otimes\cdots\otimes T_m: V_1\otimes\cdots\otimes V_m \to V_1'\otimes\cdots\otimes V_m'$ | $T_i: V \to V'$ ⇝ $T_1\wedge\cdots\wedge T_m: \Lambda^mV \to \Lambda^mV'$ |

**Note.** The universal property and the construction of linear trans. hold for $\Lambda^mV$, i.e. $T_i: V \to V'$, $i \in \{1,\dots,m\}$ ⇒ $T_1\wedge\cdots\wedge T_m: \Lambda^mV \to \Lambda^mV'$ s.t. $(T_1\wedge\cdots\wedge T_m)(v_1\wedge\cdots\wedge v_m) = T_1(v_1)\wedge\cdots\wedge T_m(v_m)$.

## The determinant

**Def.** Let $\dim(V) = n$ and $T: V \to V$ a linear operator. Consider

$$\underbrace{T\wedge\cdots\wedge T}_{n\text{ copies}}: \Lambda^nV \to \Lambda^nV,\qquad \dim(\Lambda^nV) = \binom nn = 1,\ \Lambda^nV = \operatorname{Span}(\alpha)$$

given by $T\wedge\cdots\wedge T(\alpha) = c\,\alpha$ for some scalar $c \in \mathbb{F}$. Define $\det(T) := c$.

**E.g. (whiteboard).** $V = \mathbb{R}^2$, $T(x) = \begin{pmatrix}a & b\\ c & d\end{pmatrix}x$. $\Lambda^2\mathbb{R}^2 = \operatorname{Span}\{e_1\wedge e_2\}$ ($\alpha = e_1\wedge e_2$). What is $T\wedge T = T^{\wedge 2}: \Lambda^2\mathbb{R}^2 \to \Lambda^2\mathbb{R}^2$?

$$T^{\wedge 2}(\alpha) = (T\wedge T)(e_1\wedge e_2) = T(e_1)\wedge T(e_2) = \begin{pmatrix}a\\c\end{pmatrix}\wedge\begin{pmatrix}b\\d\end{pmatrix} = (ae_1 + ce_2)\wedge(be_1 + de_2) = ad\,e_1\wedge e_2 + bc\,e_2\wedge e_1 = (ad - bc)(e_1\wedge e_2)$$

so $\det(T) = ad - bc$.

### Properties (of det)

Let $V = \mathbb{F}^n$, $\Lambda^n\mathbb{F}^n := \operatorname{Span}\{\alpha = e_1\wedge\cdots\wedge e_n\}$. Suppose $T: \mathbb{F}^n \to \mathbb{F}^n$.

1. $T(x) = (\cdots \mid \underset{i\text{th}}{w} \mid \cdots \mid \underset{j\text{th}}{w} \mid \cdots)x$ (two equal columns). Then
   $T^{\wedge n}(\alpha) = T^{\wedge n}(e_1\wedge\cdots\wedge e_n) = T(e_1)\wedge\cdots\wedge T(e_i)\wedge\cdots\wedge T(e_j)\wedge\cdots\wedge T(e_n) = T(e_1)\wedge\cdots\wedge w\wedge\cdots\wedge w\wedge\cdots\wedge T(e_n) = \mathbf{0} = 0\cdot\alpha$ ⇒ $\det(T) = 0$.
2. $T(x) = (v_1 \mid \cdots \mid v_n)x$ with $v_1,\dots,v_n$ linearly dependent, e.g. $k_1v_1 + \cdots + k_iv_i + \cdots + k_nv_n = \mathbf{0}$ for some $k_i \ne 0$ ⇒ $v_i = -\frac{k_1}{k_i}v_1 - \cdots - \frac{k_n}{k_i}v_n$ (no $v_i$ term). Then
   $T^{\wedge n}(\alpha) = T(e_1)\wedge\cdots\wedge T(e_n) = v_1\wedge\cdots\wedge v_i\wedge\cdots\wedge v_n = v_1\wedge\cdots\wedge\big(\textstyle-\frac{k_1}{k_i}v_1 - \cdots\big)\wedge\cdots\wedge v_n = \mathbf{0} + \cdots + \mathbf{0} = 0\cdot\alpha$ ⇒ $\det(T) = 0$.
3. $T(x) = (v_1 \mid \cdots \mid v_i + v_i' \mid \cdots \mid v_n)x$, $S(x) = (v_1 \mid \cdots \mid v_i \mid \cdots \mid v_n)x$, $S'(x) = (v_1 \mid \cdots \mid v_i' \mid \cdots \mid v_n)x$. Claim: $\det(T) = \det(S) + \det(S')$ (as in MAT2040).
   $T^{\wedge n}(\alpha) = v_1\wedge\cdots\wedge(v_i + v_i')\wedge\cdots\wedge v_n$ ⇒ $\det(T)\alpha = (v_1\wedge\cdots\wedge v_i\wedge\cdots\wedge v_n) + (v_1\wedge\cdots\wedge v_i'\wedge\cdots\wedge v_n) = \det(S)\alpha + \det(S')\alpha = (\det(S) + \det(S'))\alpha$.
4. $T(x) = Ax$, $S(x) = Bx$, $(T\circ S)(x) = ABx$. Claim: $\det(T\circ S) = \det(T)\det(S)$.
   $$\begin{aligned}\det(T\circ S)\alpha &= (T\circ S)^{\wedge n}(\alpha) = (T\circ S)^{\wedge n}(e_1\wedge\cdots\wedge e_n) = (T\circ S)(e_1)\wedge\cdots\wedge(T\circ S)(e_n)\\ &= T^{\wedge n}(S(e_1)\wedge\cdots\wedge S(e_n)) = T^{\wedge n}\circ(S^{\wedge n}(e_1\wedge\cdots\wedge e_n)) = T^{\wedge n}\circ S^{\wedge n}(\alpha)\\ &= T^{\wedge n}(\det(S)\cdot\alpha) = \det(S)\,T^{\wedge n}(\alpha) = \det(S)\det(T)\,\alpha\end{aligned}$$
