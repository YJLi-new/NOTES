## Matrix of the transpose map

**Prop.** $V, W$ are finite-dim vector spaces.

| | map | bases |
|---|---|---|
| $T: V \to W$ | | $A = \{v_1,\dots,v_n\}$, $B = \{w_1,\dots,w_m\}$ |
| $T^*: W^* \to V^*$ | | $B^* = \{\psi_1,\dots,\psi_m\}$, $A^* = \{\phi_1,\dots,\phi_n\}$ |

Then $\underbrace{(T_{BA})^t}_{\text{from an } m\times n \text{ matrix}} = \underbrace{T^*_{A^*B^*}}_{\text{an } n\times m \text{ matrix}}$.

*Proof.* Let $T_{BA} = (a_{ij})$, $T^*_{A^*B^*} = (b_{ij})$, i.e. $T^*(\psi_j) = \sum_{r} b_{rj}\phi_r$ ★ (← 证: 矩阵中每一元素都分别相等).

$$\begin{aligned}
T^*(\psi_j)(v_i) &= \sum_r b_{rj}\phi_r(v_i) = b_{ij}\cdot 1\\
\overset{\text{def. of } T^*}{\Rightarrow}\ \psi_j(T(v_i)) &= b_{ij}\\
\Rightarrow \psi_j\Big(\sum_{k=1}^m a_{ki}w_k\Big) &= b_{ij}\ \Rightarrow\ \sum_{k=1}^m a_{ki}\psi_j(w_k) = b_{ij}\\
\overset{\text{def. of } \psi_j}{\Rightarrow}\ a_{ji}\psi_j(w_j) &= b_{ij}\ \Rightarrow\ a_{ji} = b_{ij}
\end{aligned}$$

## Minimal Polynomials & Characteristic Polynomials

### Review on polynomials

| | Poly $\mathbb{F}[x]$ | Integer $\mathbb{Z}$ |
|---|---|---|
| ① Basis objects | irreducible polys, e.g. $x^2 + 1 \in \mathbb{R}[x]$ | prime numbers $2, 3, 5, \dots$ |
| ② Unique factorization of basis objects | e.g. $x^3 + 1 = (x+1)(x^2 - x + 1)$ | $20 = 2^2\times 5$ |
| ③ Division | $\frac{p(x)}{q(x)}$ given by $p(x) = s(x)q(x) + r(x)$, remainder $\deg r(x) < \deg q(x)$ | |

If we make the irreducible polys $p_i(x)$ in the factorization $f(x) = a_n p_1(x)^{e_1}\cdots p_k(x)^{e_k}$ to be monic, the factorization is unique.

To understand $\mathbb{F}[x]$, need to find all irred. polys in $\mathbb{F}[x]$
→ need to find a way to check whether a given poly $p(x)$ has a factor $f(x)$ or not.
If $p(x)$ has no factor other than itself (i.e. $p(x) = f(x)$), then $p(x)$ is irreducible.

understand $\mathbb{F}[x]$ ⇒ ~ all irred. polys of $\mathbb{F}[x]$ ⇒ ~ factors $f(x)$ of $\forall p(x) \in \mathbb{F}[x]$ ⇒ ~ "division" of $\forall p(x) \in \mathbb{F}[x]$ by $f(x)$.

Long division example: $x^4 - 1$ divided by $x^2 + x + 1$:

$$x^4 - 1 = (x^2 + x + 1)(x^2 - x) + (x - 1)$$

**Corollary (Root Theorem).** Let $p(x) \in \mathbb{F}[x]$. Then $(x - a)$ is a factor of $p(x) \iff p(a) = 0$.

**Theorem (Fundamental Theorem of Algebra).** (Every non-constant polynomial in $\mathbb{C}[x]$ has a root in $\mathbb{C}$.)

**Corollary.**

1. All irreducible polys in $\mathbb{C}[x]$ are of the form $\alpha x + \beta$ (i.e. of degree 1).
2. All polys in $\mathbb{C}[x]$ are of the form $p(x) = a_n(x - \alpha_1)\cdots(x - \alpha_n)$.

### ④ Greatest common divisor

To find the gcd of $(p(x), q(x))$ in $\mathbb{F}[x]$ or $(a, b)$ in $\mathbb{Z}$, use the Euclidean algorithm.

$\gcd(x^4 - 1, x^3 - x^2)$:

$$\begin{aligned}
x^4 - 1 &= (x + 1)(x^3 - x^2) + (x^2 - 1)\\
x^3 - x^2 &= (x - 1)(x^2 - 1) + (-x + 1)\\
x^2 - 1 &= (-x - 1)(-x + 1) + 0
\end{aligned}$$

so $\gcd = x - 1$ (monic). And $\gcd(18, 24) = 6$.

### ⑤ gcd for > 2 objects

$\gcd(18, 24, 36) = \gcd(\gcd(18, 24), 36)$.

### ⑥ Bézout's Theorem

If $\gcd(x, y) = g$, then $\exists a, b$ with $g = ax + by$.
