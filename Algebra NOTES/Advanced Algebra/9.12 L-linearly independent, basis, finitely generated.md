## Linear Independence

**Remark.** If $S = \{s_1,\dots,s_k\}$ is finite, then $S$ is linearly independent
$\iff$ (all $S' \subseteq S$ is linearly independent — crossed out)
$\iff$ the only solution of $\alpha_1 s_1 + \cdots + \alpha_k s_k = 0$ is $\alpha_1 = \cdots = \alpha_k = 0$.

**E.g.** $V = C^\infty(\mathbb{R})$.

1. $S = \{e^x, \cos x\}$. To see if $S$ is l.i., consider $\alpha e^x + \beta\cos x = 0$, i.e. $\alpha e^x + \beta \cos x = \mathbf{0}(x) = 0,\ \forall x \in \mathbb{R}$ (∵ 取 $x = 0$ 和 $x = 1$ …).
2. $S' = \{\cos^2 x, \sin^2 x, 1\}$ (注: $\mathbf{1}(x) = 1,\ \forall x$).
   $S'$ is l.d. $\Leftarrow$ $1\cdot\cos^2 x + 1\cdot \sin^2 x - 1\cdot \mathbf{1}(x) = 0$.

## Basis & Dimensions

**Def.** A subset $S$ is a **basis** of $V$ if ① $S$ spans $V$ and ② $S$ is l.i.

**E.g.**

1. $\{e_i = (0,\dots,0,1,0,\dots,0)^T \ (1 \text{ in the } i\text{-th coord.}) \mid i = 1,\dots,n\}$ for $V = \mathbb{R}^n$.
2. All polynomials can be written as a (finite) linear combination of $S = \{1, x, x^2, \dots\}$.
3. (blank)
4. $V = C^\infty(\mathbb{R})$, $S = \{1, x, x^2, \dots\}$: $S$ is l.i., but $\operatorname{Span}(S) \ne V$.
   e.g. $\cos x \in V$, but by Taylor expansion $\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots$ ($\infty$ terms) $\notin \operatorname{Span}(S)$.
5. There can be different bases for a vector space $V$.
   e.g. if $A = \{v_1, v_2, v_3\}$ (a basis), then $B = \{v_1 - v_2,\ v_2 - v_3,\ v_3\}$ is also a basis.

   *Proof.*
   (a) 证 $\operatorname{Span}(B) = V$: $v_3 \in \operatorname{Span}(B)$; $v_2 = (v_2 - v_3) + v_3 \in \operatorname{Span}(B)$; $v_1 = \cdots \in \operatorname{Span}(B)$
   $\Rightarrow \operatorname{Span}(A) \subseteq \operatorname{Span}(B)$ (Prop. 1.1) $\Rightarrow V \subseteq \operatorname{Span}(B)$.
   (b) $B$ is l.i.: consider $\alpha(v_1 - v_2) + \beta(v_2 - v_3) + \gamma v_3 = 0$, i.e.
   $\alpha v_1 + (-\alpha + \beta)v_2 + (-\beta + \gamma)v_3 = 0$
   $\Rightarrow \alpha = 0,\ \beta - \alpha = 0,\ \gamma - \beta = 0 \Rightarrow \alpha=\beta=\gamma=0$.

## Finitely Generated

**Def.** A vector space $V$ is **finitely generated** if $\exists$ a finite subset $S = \{s_1,\dots,s_k\}$ s.t. $V = \operatorname{Span}(S)$. ($S$ is not necessarily l.i.)

**e.g.**

- $\mathbb{R}^n = \operatorname{Span}\{e_1,\dots,e_n\}$ is f.g.
- $M_{m\times n}(\mathbb{R}) = \operatorname{Span}\{E_{ij} \mid 1\le i\le m,\ 1\le j\le n\}$ is f.g. ($E_{ij}$: 1 in the $(i,j)$ entry, 0 elsewhere)
- ★ However $V = P(\mathbb{R})$ is **not** f.g.
  Suppose on the contrary $V = \operatorname{Span}\{p_1,\dots,p_k\}$ with $\deg p_i = n_i$. Let $M = \max(n_1,\dots,n_k)$. Then $x^{M+1} \notin \operatorname{Span}\{\dots\}$, contradiction.

## Theorem

Let $V$ be f.g.; then $V$ must have a basis.

*Proof.* Let $V = \operatorname{Span}\{v_1,\dots,v_k\}$.

1. If $\{v_1,\dots,v_k\}$ is l.i., then it is a basis of $V$.
2. If it is l.d., then $\alpha_1 v_1 + \cdots + \alpha_k v_k = 0$ for $\alpha_1,\dots,\alpha_k$ not all zero.
   W.L.O.G. (by rearranging the terms) assume $\alpha_1 \ne 0$; then
   $$v_1 = \left(-\frac{\alpha_2}{\alpha_1}\right)v_2 + \cdots + \left(-\frac{\alpha_k}{\alpha_1}\right)v_k \in \operatorname{Span}\{v_2,\dots,v_k\}$$
   ∴ $\{v_1,v_2,\dots,v_k\} \subseteq \operatorname{Span}\{v_2,\dots,v_k\}$
   $\Rightarrow \operatorname{Span}\{v_1,\dots,v_k\} \subseteq \operatorname{Span}(\operatorname{Span}\{v_2,\dots,v_k\}) = \operatorname{Span}\{v_2,\dots,v_k\}$.
   Repeat … This will terminate with a l.i. spanning set.
