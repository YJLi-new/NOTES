## Remarks on linear transformations

1. $T: V \to W$ and $S: W \to U$ are linear $\Rightarrow$ $S \circ T: V \to U$ is linear.
2. $T: V \to W$ linear $\Rightarrow T(\mathbf{0}_V) = \mathbf{0}_W$.
3. Suppose $B = \{v_1,\dots,v_n\}$ is a basis of $V$ and $T: V \to W$. Then $T$ is determined by $T(v_1),\dots,T(v_n)$.
   Specifically (仅对 linear trans. 成立): $\forall v = \alpha_1 v_1 + \cdots + \alpha_n v_n \in V$, then $T(v) = \alpha_1 T(v_1) + \cdots + \alpha_n T(v_n)$.

   E.g. (证) $\forall T: \mathbb{R}^n \to \mathbb{R}^m$ linear are of the form $T(v) = Av$ ($A$ is an $m\times n$ matrix):
   consider a basis $\{e_1,\dots,e_n\}$ of $\mathbb{R}^n$. By (3), $\forall T$, let $T(e_i) = a_i \in \mathbb{R}^m$; set $A := (a_1 \mid \cdots \mid a_n)$; then $T(v) = Av$.

## Examples

- **E.g. 1.** $T: C^\infty(\mathbb{R}) \to C^\infty(\mathbb{R})$, $T(f)(x) := \int_0^x f(t)\,dt$. (证 — trans. 是否是 linear trans.)
  $$T(\alpha f + \beta g) = \int_0^x (\alpha f + \beta g)(t)\,dt = \alpha\int_0^x f(t)\,dt + \beta\int_0^x g(t)\,dt = \alpha T(f)(x) + \beta T(g)(x)$$
  So $T$ is linear.
- **E.g. 3.** $T: M_{n\times n}(\mathbb{R}) \to \mathbb{R}$, $T(A) := A_{11} + \cdots + A_{nn}$ (trace). (Ex.: 证此 linear)
- **E.g. 4.** $T: M_{n\times n}(\mathbb{R}) \to \mathbb{R}$, $T(A) := \det(A)$. $T$ is not linear ($\Leftarrow \det(A+B) \ne \det(A) + \det(B)$).
- **E.g. 5.** $T: M_{m\times n}(\mathbb{R}) \to M_{k\times n}(\mathbb{R})$, $T(A) := BA$ ($B$ is a $k\times m$ matrix). (Ex.: 证此 linear, 用 MAT2040)

## Kernel / Image of $T: V \to W$

**Def.**

$$\ker(T) = T^{-1}(\mathbf{0}) = \{v \in V \mid T(v) = \mathbf{0}\},\qquad \operatorname{Im}(T) = T(V) = \{T(v) \in W \mid v \in V\}\ (= \operatorname{range}(T))$$

- **E.g. 1.** $T: \mathbb{R}^n \to \mathbb{R}^m$, $T(x) := Ax$.
  $\ker(T) = \{x \in \mathbb{R}^n \mid Ax = \mathbf{0}\} = \operatorname{Nul}(A)$ (用 MAT2040 解方程)
  $\operatorname{Im}(T) = \{\text{all possible outputs}\} = \{Ax \in \mathbb{R}^m \mid x \in \mathbb{R}^n\} = \{x_1 a_1 + \cdots + x_n a_n \mid x = (x_1,\dots,x_n)^T\} = \operatorname{Col}(A)$
- **E.g. 2.** $T: C^\infty(\mathbb{R}) \to C^\infty(\mathbb{R})$, $T(f) = f'' + f$.
  Let $T_1(f) = f''$, $T_2(f) = \operatorname{Id}(f) = f$, both linear $\Rightarrow T = T_1 + T_2$ is linear.
  $\ker(T) = \{f \in C^\infty(\mathbb{R}) \mid f'' + f = \mathbf{0}\ (\text{zero func.})\} = \{\alpha\sin x + \beta\cos x \mid \alpha,\beta \in \mathbb{R}\} = \operatorname{Span}\{\sin x, \cos x\}$
- **Ex.** 证: if $T_1, T_2: V \to W$ are linear, then $T_1 + T_2$ is linear, and $\alpha T_1$ is linear ($\forall \alpha \in \mathbb{F}$).
- **E.g. 3.** $T: P(\mathbb{R}) \to P(\mathbb{R})$, $T(p(x)) = p'(x)$.

**Prop.** If $T: V \to W$ is linear, then ① $\ker(T) \le V$ and ② $\operatorname{Im}(T) \le W$.

*Proof of ②.* Let $w_1 = T(v_1)$, $w_2 = T(v_2) \in \operatorname{Im}(T)$. (WTS: $\alpha w_1 + \beta w_2 \in \operatorname{Im}(T)$.)
$\alpha w_1 + \beta w_2 = \alpha T(v_1) + \beta T(v_2) = T(\alpha v_1 + \beta v_2) \in \operatorname{Im}(T)$ ∎

## Rank / Nullity

**Def.** $\operatorname{rank}(T) = \dim \operatorname{Im}(T)$, $n(T) = \dim\ker(T)$.

**Theorem.** $\operatorname{rank}(T) + n(T) = \dim(V)$ ($T: V \to W$ linear).

- **E.g. 1.** $T: C^\infty(\mathbb{R}) \to C^\infty(\mathbb{R})$, $T(f) = f'' + 4f$.
  $\dim(\ker T) = \dim\{\alpha\sin 2x + \beta\cos 2x \mid \alpha,\beta \in \mathbb{R}\}$, $n(T) = 2$.
- **E.g. 2.** $T: P(\mathbb{R}) \to P(\mathbb{R})$, $T(p) = p'$.
  $\dim(\ker T) = \dim\{\alpha\mathbf{1} \mid \alpha \in \mathbb{R}\} = 1$ ($\mathbf{1}(x) = 1$);
  $\dim(\operatorname{Im} T) = \dim(P(\mathbb{R})) = \infty$ (not finitely generated).
- **E.g. 3.** $T: P_n(\mathbb{R}) \to P_{n-1}(\mathbb{R})$ ($\dim = n+1 \to \dim = n$), $T(p) = p'$.
  $\dim(\ker T) = 1$, $\dim(\operatorname{Im} T) = \dim P_{n-1}(\mathbb{R}) = n$.

**Prop. 2.18.** $T: V \to W$ is linear.

1. $T$ is injective $\iff \ker(T) = \{\mathbf{0}_V\} \iff n(T) = 0$. (injective: if $T(a) = T(b)$ then $a = b$)
2. $T$ is surjective $\iff \operatorname{Im}(T) = W \iff \operatorname{rank}(T) = \dim(W)$. (② is always true)

*Proof of ①.*
(⇒) Assume $T$ is inj. Suppose $v \in \ker(T)$ (WTS: $v = \mathbf{0}_V$). $T(v) = \mathbf{0}_W = T(\mathbf{0}_V)$ (定理) $\Rightarrow v = \mathbf{0}_V$ (此 $v$ 任取于 $\ker T$).
(⇐) Assume $\ker(T) = \{\mathbf{0}_V\}$. Suppose $T(a) = T(b)$ $\Rightarrow T(a - b) = 0 \Rightarrow a - b \in \ker(T) = \{\mathbf{0}_V\} \Rightarrow a = b \Rightarrow T$ is inj. ∎
