## Dimension

**Def.** Let $V$ be a vector space. Then

$$\dim(V) = \begin{cases}\text{number of elements in any } (\forall) \text{ basis of } V, & \text{if } V \text{ is f.g.}\\ \infty, & \text{if } V \text{ is not f.g.}\end{cases}$$

**Theorem.** $V$ a f.g. vector space $\Rightarrow$ any 2 bases ($\forall$) of $V$ must have the same (finite) number of elements.

*Proof.* $V$ is f.g. $\Rightarrow$ ∃ a finite basis $S = \{v_1,\dots,v_m\}$. Suppose $S'$ is another basis. Then $|S| < |S'|$ or $|S| > |S'|$ (需证 $|S| = |S'|$ ← 用反证: $|S| \ne |S'|$; suppose on contrary).

By switching the roles of $S$ and $S'$ if necessary, we have $|S| < |S'|$ W.L.O.G. $\Rightarrow S' = \{u_1,\dots,u_m,u_{m+1},\dots\}$.

$S$ is a basis $\Rightarrow$

$$u_1 = \alpha_{11}v_1 + \cdots + \alpha_{m1}v_m,\quad \dots,\quad u_{m+1} = \alpha_{1,m+1}v_1 + \cdots + \alpha_{m,m+1}v_m$$

The vectors $\begin{pmatrix}\alpha_{11}\\ \vdots\\ \alpha_{m1}\end{pmatrix}, \dots, \begin{pmatrix}\alpha_{1,m+1}\\ \vdots\\ \alpha_{m,m+1}\end{pmatrix} \in \mathbb{F}^m$ ($m+1$ of them) must be l.d.

∴ ∃ $\gamma_1, \gamma_2, \dots, \gamma_{m+1}$ not all zeros s.t.

$$\begin{pmatrix}\gamma_1\alpha_{11} + \cdots + \gamma_{m+1}\alpha_{1,m+1}\\ \vdots\\ \gamma_1\alpha_{m1} + \cdots + \gamma_{m+1}\alpha_{m,m+1}\end{pmatrix} = \begin{pmatrix}0\\ \vdots\\ 0\end{pmatrix}$$

Consider

$$\gamma_1 u_1 + \cdots + \gamma_{m+1}u_{m+1} = \underbrace{(\gamma_1\alpha_{11} + \cdots + \gamma_{m+1}\alpha_{1,m+1})}_{=0}v_1 + \cdots + \underbrace{(\gamma_1\alpha_{m1} + \cdots)}_{=0}v_m = 0$$

($\gamma_1,\dots,\gamma_{m+1}$ not all 0) $\Rightarrow \{u_1,\dots,u_{m+1}\}$ is l.d. ($\subseteq \{u_1,\dots,u_{m+1},\dots\} = S'$) $\Rightarrow S'$ is l.d. — contradicts with $S'$ is a basis of $V$ (l.i.).

Then $|S| \not< |S'|$ and $|S| \not> |S'|$ (前 W.L.O.G.) ∎

1. $\dim(P(\mathbb{R})) = \infty \iff P(\mathbb{R})$ is not f.g.
2. $P_n(\mathbb{R}) = \{p \in P(\mathbb{R}) \mid \deg(p) \le n\} = \operatorname{Span}\{1, x, \dots, x^n\}$ ($n+1$ 个; 有 set 能 span 它)

## Proposition 1 (Basis Extension)

$V$ is f.g. $\Rightarrow$ it has a basis $\{u_1,\dots,u_m\}$. Let $\{v_1,\dots,v_k\}$ be l.i.

Consider $B_m = \{\underbrace{v_1,\dots,v_k}_{\text{l.i.}}, \underbrace{u_1,\dots,u_m}_{\text{basis}}\}$; $\operatorname{Span}(B_m) = V$ (∵ 包含 basis).

1. If $B_m$ is l.i. (还需有), then it is a basis of $V$.
2. If $B_m$ is l.d., we have $\alpha_i \in \mathbb{F}$ ($1 \le i \le k$) and $\beta_j \in \mathbb{F}$ ($1 \le j \le m$), not all zeros, s.t.
   $$\alpha_1 v_1 + \cdots + \alpha_k v_k + \beta_1 u_1 + \cdots + \beta_m u_m = 0$$
   (若 $\forall i, \beta_i = 0 \Rightarrow \alpha_1 v_1 + \cdots + \alpha_k v_k = 0$ with $\alpha_i$ not all zeros, $\exists \alpha_i \ne 0$ $\Rightarrow$ contradicts.)
   W.L.O.G. assume $\beta_1 \ne 0$. Then $u_1 = \left(-\frac{\alpha_1}{\beta_1}\right)v_1 + \cdots$ — remove $u_1$.

## Corollary (Complementation)

If $W \le V$, $\dim V = n$, then ∃ $W' \le V$ with $V = W \oplus W'$.

*Proof.* Let $\dim(V) = n$. Then $W \le V \Rightarrow \dim(W) = m \le n$ (留 Ex.: 用反证法).

Let $\{w_1,\dots,w_m\}$ be a basis of $W$ (also l.i. in $V$). By Basis Extension, $B = \{w_1,\dots,w_m,v_{m+1},\dots,v_n\}$ is a basis of $V$. Let $W' = \operatorname{Span}\{v_{m+1},\dots,v_n\} \le V$.

1. $V = W + W'$: $\forall v \in V = \operatorname{Span}(B)$,
   $$(*)\quad v = \underbrace{\alpha_1 w_1 + \cdots + \alpha_m w_m}_{\in W} + \underbrace{\alpha_{m+1}v_{m+1} + \cdots + \alpha_n v_n}_{\in W'} \in W + W'$$
2. $V = W \oplus W'$: suppose $u \in W \cap W'$, $u = \cdots$ (见 …).
   $B$ is l.i. $\Rightarrow$ $(*)$ 的唯一解是 $\beta_1 = \cdots = \beta_m = (-\gamma_{m+1}) = \cdots = (-\gamma_n) = 0$
   $\Rightarrow u = 0 \Rightarrow W \cap W' = \{0\}$ ∎

## Linear Transformation

**Def.** $T: V \to W$ s.t. $T(\alpha v_1 + \beta v_2) = \alpha T(v_1) + \beta T(v_2)$.

**E.g. 2.** $T: C^\infty(\mathbb{R}) \to C^\infty(\mathbb{R})$, $T(f) := f''$.
