## Similar matrices

$$T_{AA} = \mathcal{C}_{AB}T_{BB}\mathcal{C}_{BA} = (\mathcal{C}_{BA})^{-1}T_{BB}\mathcal{C}_{BA}$$

$\Rightarrow T_{AA}$ and $T_{BB}$ are **similar** matrices ★ ($M$ & $N$ are similar $\Leftarrow \exists$ matrix $S$, $M = S^{-1}NS$)

$\Rightarrow T_{AA}$ & $T_{BB}$ must have the **same** eigenvalues, det, $\chi_A(x)$, diagonalizability, … for any ($\forall$) $T: V \to V$.

$\Rightarrow$ (for instance) $\det(T) := \det(T_{AA}) = \det(T_{BB})$, $\forall A, B$ bases of $V$.

## Some Constructions of Vector Spaces

### Quotient space $V/W$

Def. (preview): collection of all cosets $v + W$ ($W$ a subspace).

Idea: partition a vector space $V$ into "subspaces" (parallel affine pieces).
E.g. $V = \mathbb{R}^3$: partition into parallel planes, or parallel lines, …

### Coset

**Def.** The (right) coset determined by $v$ is the set $v + W := \{v + w \mid w \in W\}$ ($\forall v \in V$, $W \le V$).

**E.g.** $V = \mathbb{R}^3$, $W = \operatorname{Span}\{(1,0,0)^T, (0,1,0)^T\}$:

$$(0,0,1)^T + W = \{(0,0,1)^T + (a,b,0)^T \mid a, b \in \mathbb{R}\} = \{(a,b,1)^T\}\ \Rightarrow \text{the plane } z = 1$$

$W' = \operatorname{Span}\{(0,1)^T\}$ (in $\mathbb{R}^2$) $\Rightarrow (1,0)^T + W' = \{(1,\alpha)^T \mid \alpha \in \mathbb{R}\}$ = the line $x = 1$.

**Remark.** 即使 $v \ne v'$, 也可能 $v + W = v' + W$ (same coset, different way to express).

**Prop. (a)** $v + W = v' + W \iff v' - v \in W$ ★

**Prop. (b)** If $v + W \ne u + W$, then $(v + W) \cap (u + W) = \varnothing$.
E.g. $(0,0,0)^T + W$ and $(0,0,1)^T + W$ have no common vectors (two parallel planes).

*Proof of Prop. (a).*
(⇒) By assumption $v' + W = v + W \Rightarrow v' + \mathbf{0} = v + w_0$ ($\exists w_0 \in W$) $\Rightarrow v' - v = w_0 \in W$.
(⇐) Suppose $v' - v = w_1 \in W$. $\forall w$, $v' + w \in v' + W$:
$v' + w = v + w_1 + w = v + \underbrace{(w_1 + w)}_{\in W} \in v + W \Rightarrow v' + W \subseteq v + W$,
and (Ex.) $v + W \subseteq v' + W$. ∎

### Quotient space

**Def.** Let $W \le V$. The quotient space is the set $V/W := \{v + W \mid v \in V\}$.

**Remark.** 1 "element" in $V/W$ is 1 coset in $V$.

**E.g.** $V = \mathbb{R}^3$, $W' = \operatorname{Span}\{(0,0,1)^T\}$:
$V/W' = \{(0,0,0)^T + W',\ (1,0,0)^T + W',\ (1,1,0)^T + W',\ \dots\}$ = {vertical lines through each point}.

**Def./Theorem (V/W 的运算).** $V/W$ is a vector space, with

- scalar multiplication: $\alpha\cdot(v + W) := \alpha v + W$
- "vector" addition: $(v_1 + W) + (v_2 + W) := (v_1 + v_2) + W$

(A "vector" in $V/W$ ↔ a coset in $V$; in vector addition, coset + coset = coset.)

**Remark.** There's a big problem of **well-definedness**, since $\exists v' \ne v$ with $v' + W = v + W$.

E.g. (表示不同, 实际相同) $v_1 + W = v_1' + W$ with $v_1 \ne v_1'$, and $v_2 + W = v_2' + W$:
$(v_1 + W) + (v_2 + W) = (v_1 + v_2) + W$ vs. $(v_1' + W) + (v_2' + W) = (v_1' + v_2') + W$.
The addition is well-defined only when $(v_1 + v_2) + W = (v_1' + v_2') + W$ (otherwise: 1 sum, 2 outputs).

*Proof* (of $(v_1 + v_2) + W = (v_1' + v_2') + W$): $v_1 + W = v_1' + W$, $v_2 + W = v_2' + W$
$\overset{\text{Prop. (a)}}{\Rightarrow} \exists w_1 \in W$, $v_1 - v_1' = w_1$; $\exists w_2 \in W$, $v_2 - v_2' = w_2$
$\Rightarrow (v_1 + v_2) - (v_1' + v_2') = (v_1 - v_1') + (v_2 - v_2') = w_1 + w_2 \in W$
$\overset{\text{Prop. (a)}}{\Rightarrow} (v_1 + v_2) + W = (v_1' + v_2') + W$ ∎
